# ALI MU'IZ ENGLISH – النسخة التجريبية V3

هذا مشروع Flutter، ومعه إعداد بناء سحابي لإنتاج ملف APK عبر GitHub Actions.
الأسئلة الحالية تجريبية وليست أسئلة المنهج الرسمية.

## أسهل طريقة لإنتاج APK

1. افتح https://github.com من الحاسبة وأنشئ حساباً أو سجّل الدخول.
2. أنشئ مستودعاً جديداً (New repository)، واجعله Private إذا رغبت.
3. ارفع **محتويات** ملف ZIP هذا إلى المستودع، وليس ملف ZIP نفسه:
   - افتح المستودع.
   - اختر Add file ثم Upload files.
   - اسحب الملفات والمجلدات من المشروع، ثم اضغط Commit changes.
4. انتظر حتى يبدأ البناء تلقائياً. يمكنك متابعة التقدم من تبويب Actions.
5. بعد نجاح العملية (علامة خضراء)، افتح عملية Build Android APK.
6. في أسفل صفحة العملية ستجد Artifacts؛ نزّل ALI-MUIZ-ENGLISH-APK.zip.
7. فك ضغط الملف لتحصل على app-release.apk، ثم انقله إلى هاتف Android وثبّته.

## إذا لم يبدأ البناء تلقائياً

من تبويب Actions اختر Build Android APK ثم Run workflow.

## محتويات النسخة

- واجهات Home وCourse Units وLiterature وMy Progress.
